Physical constants
==================

The values of fundamental physical constants are revised periodically by CODATA. Molpro uses the values from the latest revision. Some previous values are available, see the ``lib/include/codata/`` directory. To use these system include files, simply add for instance:

.. code-block:: text

   include,codata/molpro2006

to use the values from Molpro 2006.
